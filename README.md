# Geovanny's Developer Portfolio

Welcome to my personal portfolio site! This project showcases my work as a software developer, highlighting key projects I've built using modern web technologies. The site is designed to be responsive, accessible, and dynamically rendered using JavaScript.

---

## Technologies Used

This portfolio was built using the following core technologies:

- **HTML5** — Semantic structure and layout
- **CSS3** — Responsive design, gradient backgrounds, hover effects, and dark mode styling
- **JavaScript (ES6+)** — DOM manipulation, event handling, dynamic rendering, and storage logic

---

## Features and Functionality

- **Dynamic Project Rendering**: Projects are stored in a JavaScript array and rendered dynamically using `sessionStorage`.
- **Dark Mode Toggle**: User preference is saved using `localStorage` and applied on page load.
- **Responsive Layout**: Flexbox and media queries ensure the site looks great on all screen sizes.
- **Modal Support**: Includes a modal component for additional content or messages.
- **Form Feedback**: Simulated form submission with status messaging.

---

## Dependencies

This project is built using **vanilla JavaScript** — no external libraries or frameworks are required.

However, here are some browser features it depends on:

- `sessionStorage` — for storing and retrieving project data
- `localStorage` — for persisting dark mode preference
- `querySelector` and `createElement` — for DOM manipulation
- `addEventListener` — for interactive behavior
